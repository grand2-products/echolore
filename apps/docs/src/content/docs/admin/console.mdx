管理画面 (`/admin`) は管理者ロールのみアクセスできます。

## タブ構成

| タブ | 機能 |
|------|------|
| ユーザー | ユーザー一覧、ロール変更、グループ割当、停止/復帰、招待 |
| アクセス | グループ管理、スペース権限 |
| AI 設定 | 会議エージェント定義、LLM 設定セット、**外部 AI エージェント接続 (MCP)** |
| KPI | 利用指标 |
| Google | Google 連携 (GCP 認証情報、Drive 同期) |
| 設定 | サイト・認証・メール・LLM・ストレージ・TTS・バックアップ |
| システム | システム情報、バージョン、アップデート実行 |

## ユーザー管理

- **招待** — メールアドレスで招待 (メールプロバイダ設定済みの場合)
- **ロール** — `admin` / `member`
- **停止** — `suspended` にすると全セッションが無効化

## グループと権限

グループに権限を付与できます (例: `wiki.read` / `wiki.write` / `meeting.create` / `marketing.view`)。チームスペースはグループに紐付き、スペース権限とページ権限の両方でアクセス制御します。

## LLM 設定セット

プロバイダ設定 (Gemini / Vertex / Z.ai / OpenAI 互換) を複数作成し、機能ごと (AI チャット、要約、Aituber 等) に割り当てできます。各設定で接続テストが可能です。

## システム

- 現在のバージョン表示と、アップデートの確認・実行
- 詳細な運用は [アップデートとロールバック](/operations/update/) を参照
