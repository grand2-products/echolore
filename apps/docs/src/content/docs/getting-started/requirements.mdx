## サーバー要件

| 項目 | 必要件件 | 推奨 |
|------|---------|------|
| OS | Debian 12 / Ubuntu 22.04 以降 (Linux) | — |
| メモリ | 4GB 以上 | 8GB (録画・AI 機能を使用する場合) |
| ストレージ | 20GB 以上 | 使用量に応じて |
| CPU | 2 コア以上 | 4 コア |

## ソフトウェア要件

- [Docker Engine](https://docs.docker.com/engine/install/)
- [Docker Compose v2 プラグイン](https://docs.docker.com/compose/install/linux/)

:::note
`install.sh` は Docker / Compose が未インストールの場合はエラー停止します。事前に上記リンク先からインストールしてください。
:::

## ネットワーク (開放するポート)

| ポート | 用途 |
|--------|------|
| 80/tcp | HTTP (TLS リダイレクト) |
| 443/tcp | HTTPS |
| 3478/udp | TURN (WebRTC) |
| 5349/tcp | TURN over TLS |
| 50000-50020/udp | LiveKit RTC メディア |

ufw の設定例:

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 3478/udp
sudo ufw allow 5349/tcp
sudo ufw allow 50000:50020/udp
sudo ufw reload
```

## ドメイン

DNS の A レコードをサーバーの IP アドレスに設定してください。TLS 証明書は Traefik が Let's Encrypt (ACME) で自動取得します。

## オプションの外部サービス

いずれもデプロイ後に管理画面から設定できます。

- **Google Cloud プロジェクト** — Google SSO / Gemini / Vertex AI / GCS 用
- **LLM プロバイダ** — Gemini / Vertex AI / Z.ai / OpenAI 互換
- **メールプロバイダ** — SMTP / Resend (メール認証・招待メール用)
- **ストレージプロバイダ** — S3 互換 / GCS (ファイルをクラウドに置く場合)
