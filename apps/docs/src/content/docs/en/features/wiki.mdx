The EchoLore Wiki is a block-based editor (BlockNote) for writing Notion-style pages.

## Editing pages

- **Blocks** — paragraphs, headings, lists, code blocks, quotes, images, files, dividers
- **Markdown shorthands** — e.g. type `` ``` `` to convert to a code block
- **AI shorthand** — with an LLM configured, draft and transform text from inside the editor

## Real-time collaboration

Pages sync live between everyone viewing them, including cursor positions. Collaborator avatars and connection status are shown at the top of the page.

## Structure and permissions

- **Spaces** — General (everyone) / team spaces (per group) / personal
- **Hierarchy** — parent-child page relationships, reordering
- **Page permissions** — read/write per user or group, with inheritance from parents
- **Trash** — soft-deleted pages can be restored

## History and snapshots

- Create snapshots at any time with `Ctrl+S` / `Cmd+S`
- Browse and restore past revisions from the history panel
- Export to Markdown

## AI search

Embeddings are generated automatically as you edit, making pages searchable from AI chat. Ask "How is our knowledge maintenance doing?" to get an audit report of overdue reviews, stale pages, and more.

## Knowledge governance (marketing operations)

If the marketing operations feature is enabled, Wiki pages can be registered in a governance registry that tracks owners, review deadlines, and approval status. See `docs/marketing-operations.md` in the repository for details.
