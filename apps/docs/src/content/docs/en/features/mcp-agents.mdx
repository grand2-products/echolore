EchoLore includes a built-in MCP (Model Context Protocol) server, letting external AI agents such as ChatGPT and Claude connect to your Wiki knowledge.

## Available tools

| Tool | Scope | Function |
|------|-------|----------|
| `wiki_search` | read | Vector search over the Wiki |
| `wiki_read_page` | read | Fetch a page's content as markdown (paged for long pages) |
| `wiki_list_spaces` | read | List visible spaces and writability |
| `wiki_maintenance_report` | read | Knowledge audit (overdue reviews, stale/empty pages, etc.) |
| `wiki_create_page` | write | Create a new page from markdown |

Read tools are filtered by the token creator's read permissions — information from inaccessible pages is never returned.
Tool calls are rate limited per token (60 calls per 5 minutes).

## Connecting

### OAuth-capable clients (ChatGPT / Claude connectors)

EchoLore embeds an OAuth 2.1 authorization server. Point your client at `https://<your-domain>` as the authorization server and it will be discovered automatically. On first connect, an admin consent screen is shown; once allowed, tokens are issued and refreshed automatically (30-day access tokens with rotating refresh tokens).

### Manual bearer tokens

1. Open **Admin console → AI Settings → External AI Agent Access (MCP)**
2. Choose a token name, scopes (`read` / `write`), and an expiry (never / 7 / 30 / 90 days), then issue
   - Defaults to `read` (least privilege). Add `write` only to allow page creation
3. The plaintext token (`ech_agt_...`) is **shown exactly once** — copy and store it safely

Tokens act with the issuing admin's permissions and can be revoked instantly at any time.
Recent per-token usage (success/failure, tool, timestamp) is visible in the admin console.

Configure your MCP client as follows:

```json
{
  "mcpServers": {
    "echolore": {
      "type": "http",
      "url": "https://<your-domain>/mcp",
      "headers": {
        "Authorization": "Bearer ech_agt_..."
      }
    }
  }
}
```

## Protocol

- Implements protocol revision **2026-07-28** (stateless MCP) only
  - Legacy `initialize`-handshake clients are not supported
- Stateless Streamable HTTP, POST only
- `server/discover` advertises supported versions and capabilities
- Structured output (`outputSchema` / `structuredContent`) and tool annotations are supported
- Bearer token authentication (OAuth-issued tokens use the same format)

## Agent Skills

The repository ships `skills/echolore-wiki-maintenance/SKILL.md` — a skill definition to load into agents covering audit, research, and article-creation workflows, including the rule that page creation tools may only be used on explicit request.

## Security notes

- Tokens are stored as SHA-256 hashes only (plaintext is never shown again)
- Optional token expiry (OAuth-issued tokens always expire after 30 days)
- Tokens are automatically invalidated if the issuing account is deleted or suspended
- Page creation is always attributed to the issuing user and recorded in the audit log
- OAuth consent requires an admin session; authorization codes are single-use with mandatory PKCE, and refresh tokens rotate on every use
- No tool modifies existing pages (destructive operations are excluded by design)
