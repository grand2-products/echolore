AI チャットは、Wiki の内容を根拠に回答する RAG (Retrieval-Augmented Generation) チャットです。

## 仕組み

1. 質問を受けると Wiki ページの embedding をベクトル検索
2. 関連コンテキストをシステムプロンプトに注入
3. LLM エージェントが回答を生成 (必要に応じて `wiki_search` / `wiki_read_page` ツールで追加調査)
4. 回答には引用 (該当ページへのリンク) が付く

## できることの例

- 「○○について教えて」→ 関連ページを根拠に回答
- 「最近の記事を紹介して」→ ページ一覧から要約
- 「ナレッジのメンテ状況は?」→ 監査レポート (レビュー期限超過・停滞ページ等) を要約
- 「これを記事にして」→ **対話内容から新規 Wiki ページを作成** (明示的に依頼した場合のみ)

## データソース

管理画面で連携を有効化すると、検索範囲を拡張できます。

| ソース | 説明 |
|--------|------|
| Wiki | 常時 (embedding 自動生成) |
| Google Drive | 共有ドライブのファイルを検索対象に |
| GitHub | リポジトリのドキュメントを検索対象に |

## セッション

- 会話は保存され、タイトルが自動生成されます
- ツール呼び出しの履歴 (どのページを参照したか) も記録されます

## プライバシー

チャットの検索はユーザーごとの読み取り権限でフィルタされます。読めないページの内容が回答に含まれることはありません。
