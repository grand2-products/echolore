EchoLore の Wiki はブロックベースのエディタ (BlockNote) で、Notion スタイルのページを書けます。

## ページ編集

- **ブロック編集** — 段落、見出し、リスト、コードブロック、引用、画像、ファイル、区切り線
- **Markdown ショートハンド** — `` ``` `` 入力でコードブロック変換など、入力補助あり
- **AI ショートハンド** — LLM 設定済みの場合、文章の下書き・変換をエディタ内から依頼可能

## リアルタイム共同編集

同一ページを開いているメンバーとカーソル位置ごと同期します。ページ上部に共同編集者のアバターと接続状態が表示されます。

## ページ構造と権限

- **スペース** — General (全員) / チームスペース (グループ単位) / パーソナル
- **階層構造** — ページの親子関係、並べ替え
- **ページ権限** — ユーザー/グループ単位の読み取り・書き込み、親からの継承
- **ゴミ箱** — 削除ページのソフトデリートと復元

## 履歴とスナップショット

- `Ctrl+S` / `Cmd+S` で任意時点のスナップショットを作成
- 履歴パネルから過去リビジョンの閲覧・復元
- Markdown エクスポート

## AI 検索

ページを編集すると自動で embedding が生成され、AI チャットからの検索対象になります。ナレッジのメンテナンス状況 (更新滞留・レビュー期限) は AI チャットで「ナレッジのメンテ状況は?」と聞くと監査レポートを得られます。

## ナレッジ統制 (マーケティング運用)

マーケティング運用機能を有効化すると、Wiki ページを統制レジスタに登録し、責任者・見直し期限・承認状態を管理できます。詳細は `docs/marketing-operations.md` (リポジトリ内) を参照してください。
